- **`READBACK_MISMATCH` 冲突证据链（M0 §三-5 要求，2026-11-04 补）**：M1 建议 `true`，M2/M3 建议 `false`。M2 侧证据全部来自契约原文，无需运行代码：
  1. §4.1 L161：`READBACK_MISMATCH` = 502，「写后回读与批准内容不一致；**不得返回成功**」。
  2. §4.1 L167：`READBACK_MISMATCH` **必须包含 `proposal_status=failed`**。
  3. §6.7 L672–673：「若已完成权威回读并确认内容不一致，返回 `READBACK_MISMATCH`，Proposal 转为**终态 `failed`**，**不允许再次写入**」。
  4. §6.7 L707：「Proposal 为 `failed`、`rejected` 或 `expired`：**均为终态，不允许再次写入**」。
  - 推论：若把 `retryable` 标 `true`，契约同时承诺「可重试」与「终态禁止再次写入」，二者互斥——调用方重试必然被 409/终态拒绝，属**契约自相矛盾**。故 **`READBACK_MISMATCH.retryable` 必须为 `false`**，`M1 §14.5` 建议表中该项应修正。
  - 边界：本结论只覆盖 `READBACK_MISMATCH` 一项，其余 17 码 M2 无新增异议，按 M1 §14.5 表补值。
